# Netly Landing Page

![Netly App Showcase](https://netlygo.vercel.app/app_logo.png)

This is the official landing page for **Netly** — a seamless mobile extension to LPU Autoconnect. 
Netly allows users to bypass the tedious captive portal login screen by securely saving their credentials one time using the Android Keystore System.

The landing page is built with **React** and **Vite**, featuring a premium glassmorphism UI, a sticky translucent navbar, and mobile-responsive layout.

## Features

- 🎨 **Premium Aesthetic**: Heavy use of glassmorphism, glowing gradients, and dynamic drop shadows.
- 📱 **Mobile Responsive**: Fully optimized for Android devices with scalable layouts.
- 📹 **Embedded Demo**: Embedded Google Drive preview showcasing the app in action.
- 📊 **Analytics**: Integrated Vercel Analytics for tracking custom events like APK downloads.

## Development Setup

To run the landing page locally:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deployment

This project is configured to automatically deploy to **Vercel** (`netlygo.vercel.app`) upon pushing to the `main` branch.
